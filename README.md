# 🌦️ Django Weather App (with MongoDB + Free API + IST Timezone)

A simple yet elegant **Weather Web App** built using **Django**, **Python**, and **MongoDB**, that fetches live weather data from a **free API (no key required)** and displays results in **Indian Standard Time (IST)**.  
It also stores and displays your **recent search history** from MongoDB.

## 🚀 Features

- 🌍 Fetches real-time weather for any city using the free **wttr.in API**  
- 🕒 Displays time in **Indian Standard Time (IST)**  
- 💾 Saves search results in **MongoDB**  
- 📜 Shows the **last 5 searched cities** with temperature, description, and timestamp  
- 🎨 Clean, responsive UI with simple CSS styling  
- 🔑 No API key or authentication required  

---

## 🧠 Tech Stack

| Component | Technology |
|------------|-------------|
| Backend | Django (Python) |
| Database | MongoDB (via PyMongo) |
| API | wttr.in (free weather API) |
| Frontend | HTML, CSS |
| Timezone | Asia/Kolkata (IST) |
